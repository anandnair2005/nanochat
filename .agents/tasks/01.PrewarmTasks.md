## Agent Objective
Implement a repo script that prepares a mounted Vast storage directory before the 8xH100 speedrun. The result should be executable by a cheap/small Vast instance and should avoid doing expensive setup on H100s.

## Files To Create Or Modify
- Create `runs/prewarm_vast.sh`.
- Do not modify `runs/speedrun.sh` in this task.
- Do not add Docker, Vast API, or Google Drive orchestration in this task.

## Required Behavior
- Use `#!/usr/bin/env bash` and `set -euo pipefail`.
- Require `NANOCHAT_BASE_DIR` to be set unless `NANOCHAT_ALLOW_DEFAULT_BASE_DIR=1` is supplied.
- Create `$NANOCHAT_BASE_DIR`, `$NANOCHAT_BASE_DIR/logs`, and `$NANOCHAT_BASE_DIR/status`.
- Support `NANOCHAT_NUM_SHARDS`, defaulting to `170`.
- Support `NANOCHAT_SKIP_UV_SYNC=1` to skip dependency setup.
- If dependency setup is not skipped, install `uv` if missing, create `.venv` if missing, run `uv sync --extra gpu`, and activate `.venv`.
- Restore tokenizer and run-specific checkpoints from Google Drive when `NANOCHAT_RCLONE_REMOTE` is set.
- Do not restore source-downloadable assets from Google Drive, including identity data, eval bundles, Hugging Face eval datasets, word lists, or ClimbMix.
- Run `python -m nanochat.dataset -n "$NANOCHAT_NUM_SHARDS"`.
- Do not train or evaluate the tokenizer on the prewarm instance.
- Write logs to `$NANOCHAT_BASE_DIR/logs/prewarm.log`.
- Write `$NANOCHAT_BASE_DIR/status/prewarm.STARTED` when the script begins.
- Write `$NANOCHAT_BASE_DIR/status/prewarm.DONE` only after successful completion.
- Write `$NANOCHAT_BASE_DIR/status/prewarm.FAILED` on failure.
- Print a concise summary of artifact locations at the end.

## Implementation Constraints
- Keep the script flat and easy to read.
- Avoid broad abstractions or new Python modules.
- Do not upload Google Drive artifacts in this task; restore-only is allowed.
- Do not bake in Vast-specific mount paths; rely on `NANOCHAT_BASE_DIR`.
- Do not remove or overwrite existing data under `NANOCHAT_BASE_DIR`.

## External Tools Required
- Shell, Python 3.10, and internet access.
- `uv` may be installed by the script if absent.
- `rclone` is required only when `NANOCHAT_RCLONE_REMOTE` is set.
- No MCP server is required.
- A Vast MCP or CLI helper would be useful later, but not for this task.

## Commands To Run
- `bash -n runs/prewarm_vast.sh`
- `NANOCHAT_BASE_DIR=/tmp/nanochat-prewarm-test NANOCHAT_NUM_SHARDS=0 NANOCHAT_SKIP_UV_SYNC=1 bash runs/prewarm_vast.sh`

## Acceptance Criteria
- `runs/prewarm_vast.sh` exists and passes `bash -n`.
- The script fails clearly if `NANOCHAT_BASE_DIR` is missing and `NANOCHAT_ALLOW_DEFAULT_BASE_DIR` is not set.
- The smoke command creates `logs/prewarm.log` and `status/prewarm.DONE` under the temporary base dir.
- With `NANOCHAT_RCLONE_REMOTE` set, the script invokes `runs/restore_gdrive.sh` before dataset download.
- The script supports idempotent reruns without deleting existing data.
- The final agent response lists the file changed, commands run, and whether acceptance criteria passed.

- The user wants prewarm to upload Google Drive artifacts in this same task.
