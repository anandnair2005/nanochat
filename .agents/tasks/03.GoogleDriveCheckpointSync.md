## Agent Objective
Implement scripts that restore durable artifacts from Google Drive before training and sync valuable nanochat speedrun artifacts back to Google Drive during/after training using `rclone`.

## Files To Create Or Modify
- Create `runs/sync_gdrive.sh`.
- Create `runs/restore_gdrive.sh`.
- Optionally create `runs/sync_gdrive_loop.sh` only if keeping loop behavior separate makes the implementation simpler.
- Do not modify training code.
- Do not include real credentials in the repo.

## Required Behavior
- Require `NANOCHAT_BASE_DIR`.
- Require `NANOCHAT_RUN_ID` unless `NANOCHAT_ALLOW_DEFAULT_RUN_ID=1` is set.
- Require `NANOCHAT_RCLONE_REMOTE`, for example `gdrive:nanochat-speedruns`.
- Restore shared artifacts from `$NANOCHAT_RCLONE_REMOTE/shared-artifacts/` by default.
- Restore run-specific checkpoints from `$NANOCHAT_RCLONE_REMOTE/runs/$NANOCHAT_RUN_ID/` by default.
- Sync run artifacts to `$NANOCHAT_RCLONE_REMOTE/runs/$NANOCHAT_RUN_ID/` by default.
- Support `NANOCHAT_SYNC_MODE=once` for a single blocking sync.
- Support `NANOCHAT_SYNC_MODE=loop` for repeated sync until a stop marker exists.
- Support `NANOCHAT_SYNC_INTERVAL_SECONDS`, defaulting to `600` in loop mode.
- Write logs to `$NANOCHAT_BASE_DIR/logs/gdrive_sync.log`.
- Include tokenizer, base checkpoints, SFT checkpoints, RL checkpoints if present, reports, `report.md`, status markers, and run logs.
- Support optional upload of shared tokenizer artifacts with an explicit opt-in flag.
- Do not upload source-downloadable assets to Google Drive, including identity data, eval bundles, Hugging Face eval datasets, word lists, or ClimbMix.
- Exclude `base_data_climbmix`, `.venv`, `.tmp` files, wandb local cache, and other disposable cache data by default.
- Use a run-specific remote path and avoid deleting older runs.
- Exit non-zero if final sync fails.

## Implementation Constraints
- Use `rclone copy` rather than destructive `rclone sync` unless there is a strong reason to delete remote files.
- Do not print rclone token/config contents.
- Do not assume the remote is named `gdrive`; use `NANOCHAT_RCLONE_REMOTE`.
- Keep include/exclude rules visible in the script.
- Do not sync ClimbMix shards unless a user explicitly opts in with a clearly named variable such as `NANOCHAT_SYNC_DATASET=1`.

## External Tools Required
- `rclone` installed and configured.
- Google Drive access configured outside the repo.
- No MCP server is required.
- A Google Drive MCP can help inspect remote artifacts, but `rclone` is sufficient and preferred for implementation.
