## Agent Objective
Implement the startup behavior for the Vast container. The image must be SSH/tmux friendly by default, and the actual speedrun should be started by the local orchestrator over SSH rather than unconditionally by Docker entrypoint.

## Files To Create Or Modify
- Create `runs/start_vast_container.sh`.
- Modify `Dockerfile.vast-h100` from Task 04 only if needed to set this script as the default entrypoint or command.
- Do not implement local Vast API orchestration in this task.

## Required Behavior
- Use `#!/usr/bin/env bash` and `set -euo pipefail`.
- Determine repo root from the script location.
- Default to an idle SSH/debug-ready container with no training workload running.
- Do not force SSH sessions to attach to tmux; the local orchestrator will run training inside an explicit detached tmux session.
- Support `NANOCHAT_AUTORUN=1` only as an optional override, not the default workflow.
- Support `NANOCHAT_SPEEDRUN_SCRIPT`, defaulting to `runs/speedrun_vast.sh`.
- Support `NANOCHAT_COMPLETION_DIR`, defaulting to `$NANOCHAT_BASE_DIR/status` when `NANOCHAT_BASE_DIR` is set.
- Support `NANOCHAT_LOG_FILE`, defaulting to `$NANOCHAT_BASE_DIR/logs/speedrun.log` when possible.
- Write `container.STARTED`, `container.DONE`, and `container.FAILED` markers.
- If `NANOCHAT_AUTORUN` is not `1`, print instructions and keep the container available for SSH/tmux debugging.
- If `NANOCHAT_AUTORUN=1`, run the speedrun script and propagate its exit code.
- Optionally start `sshd` if installed and `NANOCHAT_START_SSHD=1`.
- Optionally run speedrun inside tmux if `NANOCHAT_USE_TMUX=1`, but default to foreground execution for simpler status propagation. Normal orchestrated runs should create tmux sessions explicitly over SSH instead of using entrypoint autorun.

## Implementation Constraints
- The intended Vast launch mode uses the custom Docker entrypoint directly rather than Vast's interactive SSH/Jupyter entrypoints.
- Do not call `vastai destroy instance` in this task.
- Keep self-termination as a future optional feature, not default behavior.
- Do not print secret-bearing environment variables.

## External Tools Required
- Shell runtime.
- Optional `tmux` and `sshd` if corresponding env vars are enabled.
- No MCP server is required.
