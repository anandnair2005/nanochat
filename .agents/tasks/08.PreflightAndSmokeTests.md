# Task 08: Implement Preflight And Smoke Test Suite

## Status
Pending.

## Completion Notes
- Not implemented yet.
- Local preflight test runner is still pending.

## Agent Objective
Create low-cost checks that validate scripts, Docker image behavior, sync behavior, and Vast launch assumptions before using a manually created 8xH100 instance.

## Files To Create Or Modify
- Create `tasks/preflight_vast.sh` or `tasks/preflight_vast.py`; prefer shell if checks are mostly command availability and script smoke tests.
- Optionally create `tests/test_vast_scripts.py` if Python tests make script behavior easier to validate.
- Do not run real H100 workloads.

## Required Behavior
- Check shell syntax for all new `.sh` files added by earlier tasks.
- Check required command availability: `python`, `uv`, `rclone`, and optionally `docker`.
- Support `--skip-docker`.
- Support `--skip-rclone`.
- Support `--local-only` for checks that do not require external credentials.
- Run local smoke tests for prewarm, startup, and sync scripts using temporary directories.
- If Docker is available and not skipped, build or inspect the H100 image according to Task 04.
- If `VAST_API_KEY` is present and a safe flag such as `--vast-dry-run` is supplied, validate orchestrator dry-run behavior.
- Write a preflight report to `.agents/runs/preflight-<timestamp>/report.md`.

## Implementation Constraints
- The default preflight command must not create paid Vast resources.
- The default preflight command must not require Google Drive credentials.
- Use local filesystem rclone targets for sync testing.
- Keep output concise but include enough detail for debugging.
- Do not delete user cache directories.

## External Tools Required
- Shell and Python.
- Docker is optional but needed for image build verification.
- rclone is optional if `--skip-rclone` is supplied, but final workflow needs it.
- Vast MCP server is not required; a Vast CLI skill can help for live dry-run validation.

## Commands To Run
- `bash -n tasks/preflight_vast.sh` if shell implementation is used.
- `bash tasks/preflight_vast.sh --local-only --skip-docker --skip-rclone` or equivalent.
- Run Docker-enabled preflight only if Docker is available.

## Acceptance Criteria
- Preflight script exists and has help output or clear usage comments.
- Local-only preflight runs without paid cloud resources.
- The report file is created under `.agents/runs/`.
- Script syntax checks cover all Vast-related shell scripts created so far.
- The final agent response identifies which checks were run, skipped, or unavailable.

## Stop And Ask If
- The user expects the preflight to launch real Vast instances.
- Docker verification is mandatory but Docker is unavailable.
- Real Google Drive verification is mandatory but rclone credentials are unavailable.
