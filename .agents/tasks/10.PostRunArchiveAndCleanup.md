## Agent Objective
Implement the cleanup path that verifies run artifacts are safely archived before destroying Vast compute and temporary storage resources.

## Files To Create Or Modify
- Modify `tasks/vast_orchestrate.py` or the orchestration script from Task 06.
- Optionally create `tasks/cleanup_vast_run.sh` only if a separate wrapper improves usability.
- Do not add real resource IDs or personal account details.

## Required Behavior
- Add a cleanup command or mode that reads a manifest.
- Add a final artifact verification step for Google Drive/rclone destinations.
- Verify expected remote artifacts: tokenizer, base checkpoints, SFT checkpoints, report directory, final report if present, logs, status markers, and manifest/metadata.
- Refuse to destroy storage if artifact verification fails unless `--force` is supplied.
- Destroy the manually created H100 instance after successful final sync or when forced.
- Destroy the single Vast storage volume after successful artifact verification or when forced.
- Mark cleanup status in the manifest.
- Make cleanup idempotent so rerunning does not fail if resources are already gone.

## Implementation Constraints
- Prefer local Vast credentials only.
- Do not call cleanup from inside the training container by default.
- Do not delete Google Drive artifacts in this task.
- Do not destroy resources by default in dry-run mode.
- If the API cannot distinguish storage types safely, stop and ask before implementing destructive storage deletion.

## External Tools Required
- Vast API key and Vast CLI/SDK/API access for real cleanup.
- `rclone` for remote artifact verification.
- Optional Vast MCP server or CLI skill can help inspect and destroy resources safely.

## Commands To Run
- Run cleanup help output, for example `python tasks/vast_orchestrate.py cleanup --help`.
- Run cleanup dry-run against a synthetic manifest.
- Run artifact verification against a local filesystem rclone target if supported.
- Do not destroy real resources unless the user explicitly approves.

## Acceptance Criteria
- Cleanup command exists and can read a manifest.
- Dry-run cleanup prints the exact resources that would be destroyed.
- Artifact verification can pass against a local test archive.
- Cleanup refuses destructive actions when verification fails unless forced.
- The final agent response states whether any real resources were touched.

## Stop And Ask If
- Live cleanup is required and no Vast API key is available.
- Manifest data is insufficient to identify resources safely.
- The user asks to force cleanup despite failed artifact verification.
